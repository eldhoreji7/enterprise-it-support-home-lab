# Lab Architecture

## Enterprise IT Support & Microsoft 365 Home Lab

The lab simulates a small business IT environment with a Windows endpoint, local administration and Microsoft cloud identity services.

### Current Architecture

MacBook Air M1  
↓  
UTM Virtualization  
↓  
Windows 11 ARM — LAB-PC01  
↓  
Windows Local Administration  
- Local users and groups
- Administrator vs standard-user permissions
- TCP/IP troubleshooting
- DNS troubleshooting
- Account lifecycle management

Microsoft Azure / Microsoft Entra ID  
↓  
Cloud Identity Administration  
- User provisioning
- Password resets
- Account disable / enable
- Session revocation
- Sign-in log investigation
- Security group management
